# 07 - UI & Frontend — PsycheWard

## 1. Stack

| Thứ | Dùng cho |
|---|---|
| React + Vite | Component-based UI, client-side routing |
| boardgame.io/react | `Client` component — kết nối server, nhận `G`/`ctx`/`moves` tự động |
| TailwindCSS (v4) | Layout, spacing, responsive — kết hợp với class dùng chung ở `index.css` |
| Framer Motion | Animation (lật thẻ, hiệu ứng dùng thuốc, thẻ bay) |
| Zustand | UI state ngoài game: guest session, lobby state |
| socket.io-client | Chat namespace `/chat` (song song với boardgame.io) |

boardgame.io/react lo toàn bộ connection và state sync — Zustand **không** chứa game state, chỉ chứa UI state (guest session, lobby, chat).

```
│   "Trị lành hay điên thêm?"   │
│                                │
│  Tên của bạn:                  │
│  [CrazyNurse#4821        ] [✏] │
│                                │
│  [  + Tạo phòng mới  ]        │
│  [ → Vào phòng có sẵn ]       │

```

Flow:
1. Load guest session từ localStorage.
2. "Tạo phòng" → `POST /lobby/create` → nhận `matchID` → `POST /lobby/join` seat 0 → vào `/game/{matchID}`.
3. "Vào phòng" → nhập mã → `POST /lobby/join` seat tiếp theo trống → vào `/game/{matchID}`.

## 4. Board component — cách đọc state

```jsx
// client/src/components/game/Board.jsx
export function Board({ G, ctx, moves, playerID, isActive }) {
  const myIndex = Number(playerID);
  const me = G.players[myIndex];
  const isMyTurn = ctx.currentPlayer === playerID;
  const inSideEffectWindow = ctx.phase === "sideEffectWindow";
  const canReact = inSideEffectWindow && !isMyTurn;  // không phản ứng vào chính mình

  // Kiểm tra game over
  if (ctx.gameover) {
    return <WinScreen winner={ctx.gameover.winner} finalState={G.players} />;
  }

  return (
    <div className="game-layout">
      {G.players.map((p, i) => (
        <PlayerArea
          key={i}
          player={p}
          isMe={i === myIndex}
          isCurrentTurn={ctx.currentPlayer === String(i)}
        />
      ))}

      {isActive && !inSideEffectWindow && (
        <HandArea hand={me.hand} moves={moves} G={G} ctx={ctx} />
      )}

      {inSideEffectWindow && G.sideEffectWindow && (
        <SideEffectWindow
          window={G.sideEffectWindow}
          canReact={canReact}
          onReact={(slug) => moves.reactSideEffect({ disorderSlug: slug })}
          onSkip={() => moves.skipSideEffect()}
        />
      )}

      <StatusBar G={G} ctx={ctx} onPass={() => moves.passTurn()} isMyTurn={isMyTurn} />
    </div>
  );
}
```

## 5. Chat Panel — scrollable

```jsx
// client/src/components/ui/ChatPanel.jsx
export function ChatPanel({ matchID, displayName, allowChat, lastAction }) {
  const feedRef = useRef(null);
  const [messages, setMessages] = useState([]);
  const [newCount, setNewCount] = useState(0);
  const isAtBottom = useAtBottom(feedRef);

  // System banner từ lastAction (G.lastAction thay đổi)
  useEffect(() => {
    if (!lastAction) return;
    setMessages(prev => [...prev, { type: "system", ...lastAction }]);
  }, [lastAction]);

  // Scroll tự động chỉ khi đang ở cuối
  useEffect(() => {
    if (isAtBottom) {
      feedRef.current?.scrollTo({ top: feedRef.current.scrollHeight, behavior: "smooth" });
      setNewCount(0);
    } else {
      setNewCount(n => n + 1);
    }
  }, [messages]);

  return (
    <div className="glass-card chat-panel">
      <div ref={feedRef} className="chat-feed overflow-y-auto">
        {messages.map((m, i) => (
          m.type === "system"
            ? <SystemBanner key={i} action={m} />
            : <ChatBubble key={i} message={m} isMe={m.displayName === displayName} />
        ))}
      </div>
      {newCount > 0 && !isAtBottom && (
        <button className="new-msg-badge" onClick={() => scrollToBottom(feedRef)}>
          ▼ {newCount} tin mới
        </button>
      )}
      {allowChat && <ChatInput onSend={(text) => sendChat(matchID, displayName, text)} />}
    </div>
  );
}
```

## 7. Timer

Countdown `MM:SS` hoặc progress bar — click toggle, lưu preference vào `localStorage`.

boardgame.io không có turn timer built-in. Mình tự implement:
- Server: `setTimeout` trong `turn.onBegin` gọi `moves.passTurn()` sau `turnTimeout` giây.
- Client: countdown từ `turnTimeout` khi nhận `ctx.turn` mới.

Màu: > 50% → `--accent-teal`, 20–50% → `--warning`, < 20% → `--danger` + nhấp nháy.
