# 07 - UI & Frontend — PsycheWard

## 1. Stack

| Thứ | Dùng cho |
|---|---|
| React + Vite | Component-based UI, client-side routing |
| TailwindCSS (v4) | Layout, spacing, responsive — kết hợp với class dùng chung ở `index.css` |
| Framer Motion | Animation (lật thẻ, hiệu ứng dùng thuốc, thẻ bay) |
| Zustand | Global state (game state, guest session) |
| React Query | Fetch API (room config, card data) |

## 2. Theme — màu sắc, font, background

Palette định nghĩa một lần trong `frontend/src/config/theme.js` (tham chiếu JS), nguồn sự thật thực sự là CSS variable khai báo trong `:root` ở `index.css`. Không hardcode màu trong component.

```css
:root {
  /* Background */
  --bg-from:        #0f172a;              /* nền gradient — xanh đen đậm */
  --bg-to:          #020617;              /* nền gradient — gần đen */

  /* Cards & surfaces */
  --card-bg:        rgba(15, 23, 42, 0.8);
  --card-border:    rgba(148, 163, 184, 0.1);

  /* Text */
  --text:           #e2e8f0;
  --text-strong:    #f8fafc;
  --text-muted:     #94a3b8;
  --text-faint:     #64748b;
  --text-faintest:  #475569;

  /* Accent — bệnh viện tâm thần: xanh lá bệnh + trắng vô trùng */
  --accent-green:   #22c55e;              /* màu "trị lành", thành công */
  --accent-teal:    #14b8a6;              /* gradient nút chính */
  --accent-red:     #ef4444;              /* nguy hiểm, Episode cards */
  --accent-purple:  #a855f7;              /* Disorder cards */
  --accent-yellow:  #eab308;              /* warning, Side Effect window */

  /* Inputs */
  --input-bg:       rgba(255, 255, 255, 0.05);
  --input-border:   rgba(255, 255, 255, 0.1);

  /* Status */
  --success:        #22c55e;
  --warning:        #f59e0b;
  --danger:         #f87171;

  /* Card type colors */
  --disorder-bg:    #3b0764;              /* tím tối */
  --drug-bg:        #14532d;              /* xanh lá tối */
  --therapy-bg:     #713f12;             /* vàng nâu */
  --episode-bg:     #7f1d1d;             /* đỏ tối */
}
```

**Class dùng chung** (khai báo trong `index.css`):

| Class | Dùng cho |
|---|---|
| `.glass-card` | Card nền mờ, viền mảnh, bo góc 16px, blur backdrop |
| `.gradient-text` | Chữ gradient teal→green — tiêu đề, tên game |
| `.logo-mark` | Icon 💊 trong vòng tròn teal — logo app |
| `.avatar-pill` | Badge tên người chơi hình pill (bo góc nhiều) |
| `.form-label` / `.form-input` / `.form-hint` / `.form-error` | Form elements |
| `.btn` + `.btn-primary` / `.btn-secondary` / `.btn-danger-outline` | 3 biến thể nút |
| `.status-pill` (`.ready` / `.waiting`) + `.status-dot` | Badge sẵn sàng/chờ |
| `.toggle-row` | Hàng checkbox + label |
| `.card-disorder` / `.card-drug` / `.card-therapy` / `.card-episode` | Card type styling |
| `.vulnerable-glow` | Glow xanh vàng khi đang "hở" side effects |
| `.side-effect-banner` | Banner Side Effect Window (nền vàng nhạt) |

**Mapping cụ thể:**
- Disorder card trong psyche: nền `--disorder-bg`, viền tím nhạt.
- Drug card trong hand: nền `--drug-bg`, viền xanh lá nhạt.
- Therapy card trong hand: nền `--therapy-bg`, viền vàng nhạt.
- Episode card trong hand: nền `--episode-bg`, viền đỏ nhạt.
- Người đang vulnerable: glow vàng `--accent-yellow` quanh psyche area.
- Side Effect Window banner: nền `rgba(234,179,8,0.15)`, chữ `--accent-yellow`.
- Disorder vừa trị: animation fade + scale down rồi remove khỏi psyche.
- Disorder mới thêm vào: animation slide-in từ trên xuống.

**Font:** `'Inter', 'Segoe UI', system-ui, sans-serif` — set một lần trên `body`.

**Background:** 
- **Ban ngày (ngoài ván):** `radial-gradient(ellipse at top, var(--bg-from) 0%, var(--bg-to) 100%)` — xanh đen, cảm giác bệnh viện ban đêm.
- **Trong ván:** Giữ nguyên background, **không tối thêm** (khác với Ma Sói). Thay vào đó, panel game có nền khác biệt qua `--card-bg` để phân tách vùng.
- Background **không thay đổi** theo phase — PsycheWard không có đêm/ngày như Ma Sói.
- Thêm lớp `body::before` với pattern rất mờ (hình viên thuốc hoặc dấu thập y tế lặp lại, opacity 0.03) để tạo texture.

## 3. Layout & Screens

### Landing Page (`/`)

Thay toàn bộ Login/Register bằng 1 trang Landing:

```
┌────────────────────────────────┐
│        💊 PsycheWard           │  ← logo-mark + gradient-text
│   "Trị lành hay điên thêm?"   │  ← tagline
│                                │
│  Tên của bạn:                  │
│  [CrazyNurse#4821        ] [✏] │  ← input, nút edit để đổi tên
│                                │
│  [  + Tạo phòng mới  ]        │  ← btn-primary
│  [ → Vào phòng có sẵn ]       │  ← btn-secondary + input mã phòng
└────────────────────────────────┘
```

- Tên tự động điền từ localStorage (hoặc generate mới).
- Click nút edit → input text để đổi tên (validate realtime).
- "Tạo phòng" → tạo phòng + vào `/room/{code}`.
- "Vào phòng" → nhập mã + vào `/room/{code}`.

**Psyche area của mỗi người:**
- Hiển thị tối đa 4 (hoặc nhiều hơn trong Chaos Mode) Disorder cards úp ngửa.
- Có tên + trạng thái vulnerable (glow vàng nếu đang hở).

- Drug: chọn Disorder trong psyche của mình để trị.
- Episode: chọn người chơi khác để nhắm (disabled với người không còn active).

## 4. Chat Panel

### Feed cuộn (Scrollable)

Chat panel có `max-height` cố định và `overflow-y: auto` (thanh cuộn). **Không phải toàn màn hình** — chỉ chiếm phần bên phải (desktop) hoặc phần dưới (mobile).

**Cuộn tự động:**
- Tin nhắn mới → tự cuộn xuống cuối **chỉ khi** người dùng đang ở cuối (scrollTop + clientHeight ≥ scrollHeight - 20px).
- Nếu người dùng đang cuộn lên đọc lại → **không** tự nhảy xuống — hiển thị badge "▼ X tin mới" ở góc dưới, click để nhảy xuống.

### Loại tin nhắn

- **Chat bubble** — lời chat người chơi (nếu `allow_chat` bật). Bubble của bạn căn phải.
- **System banner** — sự kiện game (lượt đi, dùng thẻ, trị bệnh, kết quả Side Effect). Màu theo `kind`:
  - `cure` — xanh lá (Disorder đã trị)
  - `episode` — đỏ nhạt (Episode card kích hoạt)
  - `side_effect` — vàng (Side Effect Window)
  - `turn` — teal nhạt (lượt mới)
  - `system` — xám (thông tin hệ thống)
  - `win` — xanh + confetti animation

- Hiển thị overlay nhỏ (không che toàn màn hình) phía dưới bài.

- Chỉ hiển thị khi **không phải lượt của bạn** (bạn mới vừa dùng Drug thì bạn không phản ứng được vào chính mình).
- Sau khi chọn / bỏ qua / hết giờ → ẩn overlay.

## 6. Timer

Timer `MM:SS` hoặc progress bar — click vào timer để toggle giữa 2 chế độ, lưu preference vào `localStorage`.

Màu theo % còn lại:
- > 50% → `--accent-teal`
- 20–50% → `--warning`
- < 20% → `--danger` + nhấp nháy nhẹ

## 7. Animation (Framer Motion)

| Animation | Mô tả |
|---|---|
| Card flip (game start) | Lật thẻ reveal Disorder khi chia bài — 3D flip, 0.5s |
| Disorder cured | Scale down + fade out + màu xanh flash khi trị bệnh |
| Disorder added | Slide in từ trên xuống, rung nhẹ (shake) khi bị thêm bệnh |
| Card play | Thẻ từ hand "bay" đến target area, 0.3s |
| Episode hit | Target player card "rung" khi bị Episode nhắm |
| Win screen | Confetti + zoom in tên người thắng |

## 8. State management (Zustand)

**`gameStore.js`** — toàn bộ game state:
- `phase`, `turnNumber`, `currentPlayerIndex`
- `players`: `[{seatIndex, displayName, psyche, isVulnerable, isActive, isCurrentTurn}]`
- `myHand`: `[CardMeta]` — riêng tư
- `feed`: `[{type, content, timestamp}]` — chat + system banners gộp
- `sideEffectWindow`: `{open, targetName, vulnerableTypes, secondsLeft}` | `null`
- `roomSettings`: `RoomConfig`

**`guestStore.js`** — guest session:
- `guestId`, `displayName`
- `setDisplayName(name)` — cập nhật localStorage + gửi `RENAME` event

WebSocket dispatch vào store trong `hooks/useWebSocket.js` — một chỗ duy nhất.
